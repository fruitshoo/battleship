# Blood Splatter Decals

Downscaled game-ready derivatives of Resource Boy blood texture assets.

- Source: Resource Boy blood textures, provided locally with `License.txt`
- License summary: royalty-free use in personal and commercial projects; modification is allowed; attribution is not required; standalone resale, sublicensing, or redistribution of the asset files is prohibited
- Processing: resized to a maximum edge of 512 px from the supplied high-resolution PNGs

Keep these files embedded as part of the game project, not redistributed as a separate texture pack.
